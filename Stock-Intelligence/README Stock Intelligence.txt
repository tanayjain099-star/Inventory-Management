Stock Intelligence

Stock Intelligence is a modern, AI-powered Inventory Management System (IMS) designed to digitize and optimize stock operations for small to medium enterprises. Built with a stunning glassmorphic UI, it provides real-time tracking, intelligent forecasting, and automated alerts to ensure you never miss a beat in your supply chain.

Key Features
AI-Driven Insights
•Demand Forecasting: Predictive analytics for 7-day and 30-day stock requirements.
•Inventory Health Score: A real-time 0-100 metric evaluating your overall efficiency.
•Anomaly Detection: Automated alerts for dead stock, overstock, and critical imbalances.
•Smart Chatbot: Query your inventory using natural language (e.g., "What's low on stock?").

 Real-Time Operations
•Multi-Warehouse Support: Manage stock across different locations seamlessly.
•Transaction Lifecycle: Track Receipts, Deliveries, and Internal Transfers with a 3-step validation flow.
•Stock Adjustments: Log physical count corrections with detailed reasoning.
•Dynamic Dashboard: KPI cards and Legended charts for an instant business snapshot.

 Smart Reminders
•Automated Alerts: Low stock and stockout notifications triggered in real-time.
•Task Management: Prioritized reminders for counts, reorders, and supplier meetings.

 Technology Stack
•Frontend: React 19 + Vite 8
•Animations: Framer Motion
•Charts: Recharts (Customized for dark-mode)
•Icons: React Icons (HeroIcons)
•Persistence: LocalStorage (Zero-database setup for demos)
•Styling: Pure CSS (Glassmorphism & Radial Gradients)
•Quick Start

1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (LTS) installed on your system.

2. Setup
Clone the repository and install dependencies:
```bash
npm install
```
 3. Launch
Run the development server:
```bash
npm run dev
```
The app will be available at `http://localhost:5173`.
